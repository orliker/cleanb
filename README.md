# Bright Infinity website

Production website for a cleaning, renovation and property-services business operating in Portugal and Angola.

Live site: [brightinfinitypt.com](https://www.brightinfinitypt.com/)

## What was delivered

- Responsive service-business website in Portuguese
- Modular sections for services, company profile, locations, portfolio, team, process, FAQ and contact
- Lead-generation paths through a contact form and WhatsApp
- SEO title, description, canonical URL and social metadata
- Smooth scrolling and motion while preserving a clear mobile experience

## Stack

- React 19 and TypeScript
- Vite
- Tailwind CSS 4
- Framer Motion, GSAP and Lenis
- Component-based content and reusable service data

## Quality focus

The implementation separates content, reusable UI sections and visual assets so the site is easier to maintain. It includes responsive layouts, structured headings and production metadata for discoverability and consistent link previews.

## Role

End-to-end web implementation: requirements translation, component architecture, responsive frontend, content structure, conversion paths, QA and production delivery.
